# Mogu Mogu Lychee - Scroll Animation Landing Page

A premium scroll-triggered canvas frame animation using GSAP & ScrollTrigger, integrated with Mogu Mogu's Lychee brand styling.

## Local Development

To run the project locally:

1. Ensure you have Node.js installed.
2. Run the server using:
   ```bash
   node server.js
   ```
3. Open your browser and navigate to `http://localhost:3000`.

## Vercel Deployment

This repository is optimized for instant deployment on **Vercel** with zero-configuration:

1. Go to [Vercel](https://vercel.com/) and log in.
2. Click **New Project**.
3. Import this GitHub repository (`First-animation`).
4. Keep the default settings (Vercel automatically detects the static HTML project).
5. Click **Deploy**.

Vercel will build and host your website as a static application, serving your animation and marketing sections instantly.
